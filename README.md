# Arya Patel - Creative Portfolio

A premium, highly interactive personal portfolio built for Arya Patel, a Full-Stack Developer specializing in AI Products.

## 🚀 Overview

This repository contains the source code for a modern, high-performance web portfolio that emphasizes smooth animations, a dark luxury aesthetic, and responsive design.

### Key Features
- **Premium Aesthetics**: Dark luxury theme with neon electric borders.
- **Smooth Animations**: Powered by GSAP and Lenis for silky smooth scrolling and staggering text effects.
- **Interactive Elements**: Includes interactive components and potentially WebGL shaders.
- **Modern Tech Stack**: React + Vite for lightning-fast development and optimized production builds.

## 🛠️ Technology Stack

- **Framework**: React
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Animations**: GSAP (GreenSock Animation Platform)
- **Smooth Scrolling**: Lenis
- **Language**: TypeScript

## ⚙️ Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/arya1411/arya-creative-portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Arya_Portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

To start the development server, run:
```bash
npm run dev
```
Open your browser and visit the URL provided in your terminal (typically `http://localhost:5173`).

### Building for Production

To create an optimized production build:
```bash
npm run build
```
This will generate the built assets in the `dist` folder.
